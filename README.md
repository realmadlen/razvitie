# Развитие

Личное PWA для ежедневного обучения: 3 темы в месяц, 15–30 минут в день, интервальное повторение (FSRS), ассоциации, разминка по математике и логике, аналитика прогресса.

```
npm install
npm run dev
```

Сайт: https://realmadlen.github.io/razvitie/ — собранная `dist` публикуется в ветку `gh-pages`.
